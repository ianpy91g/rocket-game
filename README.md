# 水火箭發射（網頁版）

用 ORIORI 握力球發射水火箭：握緊打氣（至少 1 秒），放開那一瞬間的握力決定火箭飛多高。

**開始玩：** https://ianpy91g.github.io/rocket-game/

- 自由挑戰，可以一直試。放開時的握力（放開前 0.6 秒內的最高值）決定等級與高度：

  | 握力 | 等級 |
  |---|---|
  | 10 以下 | 發射失敗 |
  | 10～14 | 1 越過樹梢 |
  | 15～19 | 2 超越台北 101 |
  | 20～24 | 3 穿過雲層 |
  | 25～29 | 4 飛越玉山 |
  | 30～34 | 5 對流層頂 |
  | 35～39 | 6 平流層・臭氧層 |
  | 40～44 | 7 中氣層・流星 |
  | 45～49 | 8 卡門線・太空邊界 |
  | 50～54 | 9 增溫層・太空站 |
  | 55 以上 | 10 外太空（握力越大越遠，75 以上飛到月球） |

- 同一等級內再依握力細分高度。打氣不到 1 秒就放開不算發射。
- 圖鑑：飛到哪一層就解鎖那一張，保留在這台裝置上，大家一起收集。
- 右側列出這位玩家的最佳紀錄與最近 10 次；「換人挑戰」（按兩次確認）只清空紀錄，圖鑑保留。
- 沒有握力球時，按住畫面也能打氣（按越久力道越大）。背景音樂可在左上角開關（鍵盤 M）。

## 瀏覽器

iPad / iPhone 請用 **Bluefy**（Safari 不支援網頁藍牙）；Android 與電腦用 Chrome / Edge。

## 檔案

- `rocket.js`：遊戲本體（畫圖、邏輯、音效、音樂），不碰 DOM，可在 Node 測試
- `app.js`：畫面縮放、觸控、Web Bluetooth（服務 `FFB0`、握力通道 `FFB2`）、存檔
- `index.html`：小外殼，每次以時間參數載入上面兩個檔，避免 Bluefy 拿到快取的舊版
- 發佈新版時記得改 `rocket.js` 的 `VERSION`，畫面右下角會顯示
